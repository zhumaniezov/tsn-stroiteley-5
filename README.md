# 🏠 ТСН «Строителей 5»

Сайт товарищества собственников недвижимости.
Адрес дома: Московская область, г. Котельники, ул. Строителей, д. 5.

## 🛠 Стек

- **Frontend** — чистый HTML/CSS/JS (без сборки, без npm)
- **БД и API** — [Supabase](https://supabase.com) (PostgreSQL + REST + Auth)
- **Хостинг** — [Vercel](https://vercel.com) (бесплатный план)
- **Репозиторий** — GitHub

Бесплатно для MVP. Платное — только домен (опционально, ~500 ₽/год).

## 📁 Структура


## 🚀 Развёртывание — пошагово

### Шаг 1. Создать репозиторий на GitHub (5 минут)

1. Зайдите на [github.com](https://github.com), если нет аккаунта — зарегистрируйтесь.
2. Нажмите **+ → New repository** в правом верхнем углу.
3. Имя репозитория: `tsn-stroiteley-5` (или любое другое).
4. Visibility: **Public** (для бесплатного Vercel).
5. **Не ставьте** галочки «Add README», «Add .gitignore» — у нас уже есть свои.
6. Нажмите **Create repository**.

### Шаг 2. Загрузить файлы

**Способ A — через веб-интерфейс GitHub (проще):**

1. На странице нового репозитория нажмите **uploading an existing file**.
2. Перетащите все файлы из этой папки (`index.html`, `styles.css`, `app.js`, и т.д.).
3. **Важно:** папку `supabase/` тоже нужно загрузить — для этого либо перетащите её содержимое вручную, либо используйте способ Б.
4. Внизу нажмите **Commit changes**.

**Способ Б — через командную строку (если умеете):**

```bash
cd tsn-site
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/tsn-stroiteley-5.git
git push -u origin main
```

### Шаг 3. Настроить Supabase (10 минут)

1. Зайдите на [supabase.com](https://supabase.com) → **Start your project** → войдите через GitHub.
2. **New project** → введите имя `tsn-stroiteley-5`, придумайте пароль для БД (запишите!), регион выберите **Frankfurt** (ближайший к РФ).
3. Подождите ~2 минуты, пока проект создастся.
4. Слева в меню откройте **SQL Editor** → **New query**.
5. Откройте файл `supabase/schema.sql` из вашего репозитория, скопируйте всё содержимое, вставьте в редактор и нажмите **Run**.
6. Должно появиться зелёное «Success». Это создало таблицы `news` и `requests` и заполнило их примерными данными.
7. В меню слева **Settings → API**. Скопируйте:
   - **Project URL** (вверху страницы)
   - **anon public** key (в разделе «Project API keys»)

### Шаг 4. Прописать ключи в config.js

1. На GitHub откройте свой репозиторий → файл `config.js` → нажмите карандаш (Edit).
2. Замените:
   - `YOUR_SUPABASE_URL_HERE` → ваш Project URL (например, `https://abcdefgh.supabase.co`)
   - `YOUR_SUPABASE_ANON_KEY_HERE` → ваш anon public key (длинная строка)
3. Внизу нажмите **Commit changes**.

> ⚠️ **anon key — публичный**, его безопасно размещать в открытом коде. Но **никогда** не размещайте `service_role key` — он даёт полный доступ.

### Шаг 5. Деплой на Vercel (3 минуты)

1. Зайдите на [vercel.com](https://vercel.com) → войдите через GitHub.
2. Нажмите **Add New → Project**.
3. Найдите свой репозиторий `tsn-stroiteley-5` → **Import**.
4. Все настройки оставьте по умолчанию (Framework: **Other**).
5. Нажмите **Deploy**.
6. Через ~30 секунд сайт будет доступен по адресу типа `tsn-stroiteley-5.vercel.app`.

🎉 **Готово!** Сайт работает.

## 📝 Как обновлять контент

### Добавить новость

1. Откройте Supabase → **Table Editor** → таблица `news`.
2. Нажмите **+ Insert** → **Insert row**.
3. Заполните:
   - `title` — заголовок
   - `category` — например, «Важно», «Сервис», «Дом»
   - `excerpt` — краткий текст (показывается у больших карточек)
   - `published_at` — дата публикации (по умолчанию текущая)
4. **Save**. Новость появится на сайте через 1-2 секунды.

### Просмотр заявок жильцов

1. Supabase → **Table Editor** → таблица `requests`.
2. Все новые заявки появляются здесь.
3. Меняйте поле `status` для отслеживания: `new` → `in_progress` → `done`.

### Изменить тарифы / контакты / тексты

Это сейчас «зашито» в HTML. Чтобы изменить:

1. На GitHub откройте `index.html` → карандаш (Edit).
2. Используйте Ctrl+F (поиск), найдите нужное место (например, телефон).
3. Замените, нажмите **Commit changes**.
4. Vercel автоматически переразвернёт сайт через ~30 секунд.

## 🌐 Подключить свой домен (опционально)

1. Купите домен (например, `stroiteley5.ru`) на reg.ru или nic.ru — ~500 ₽/год.
2. Vercel → ваш проект → **Settings → Domains** → добавить домен.
3. Vercel покажет DNS-записи, которые нужно прописать у регистратора.
4. SSL-сертификат настроится автоматически.

## 🆘 Если что-то не работает

- **Сайт открывается, но без новостей** → проверьте `config.js` (правильные ли ключи?). Откройте в браузере консоль (F12) — там будут ошибки.
- **Форма заявок не отправляется** → проверьте, что выполнили шаг с SQL (таблица `requests` существует) и что RLS-политики на месте.
- **Vercel не деплоит** → убедитесь, что репозиторий публичный, либо подключите Vercel Pro.

При проблемах присылайте скриншот консоли браузера (F12 → Console) — там видно, что не так.
